# Contributing

Thanks for taking an interest in LedgerFlow.

## Development

1. Use Node.js 20 or later.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.
4. Run `npm test` and `npm run build` before opening a pull request.

## Pull requests

- Keep changes focused and explain the accounting or user workflow they affect.
- Add tests when changing reconciliation rules or CSV parsing.
- Do not commit customer data, credentials, generated build output or dependency folders.
- Preserve clear labels, keyboard access and responsive layouts.
