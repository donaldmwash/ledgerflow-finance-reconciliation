# Security Policy

This repository is a portfolio demonstration and should not be used to process real financial records without a separate security and privacy review.

## Reporting a vulnerability

Please do not publish credentials, personal financial data or exploit details in a public issue. Contact the repository owner privately through the contact details on the GitHub profile and include a concise description, impact and reproduction steps.

## Data handling

LedgerFlow processes imported CSV data in the browser. Do not upload real customer or account information to a public demo. Review and verify all reconciliation results against original source documents.
